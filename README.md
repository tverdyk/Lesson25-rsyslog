# Lesson25-rsyslog

Цель домашнего задания
Научится проектировать централизованный сбор логов. Рассмотреть особенности разных платформ для сбора логов.

Описание домашнего задания
1. В Vagrant разворачиваем 2 виртуальные машины web и log
2. на web настраиваем nginx
3. на log настраиваем центральный лог сервер на любой системе на выбор
journald;
rsyslog;
elk.
4. настраиваем аудит, следящий за изменением конфигов nginx 

Все критичные логи с web должны собираться и локально и удаленно.
Все логи с nginx должны уходить на удаленный сервер (локально только критичные).
Логи аудита должны также уходить на удаленную систему.

Развертывание стенда на 3 ВМ , ОС Убунту 20.04  ansible 
1 Создать 3 ВМ 
   WEB - сам вебсервер - передает логи nginx
   Rsyslog- сервер для приема логов
   Server - передает все логи. 
2  Загружаем инвентори с плейбуками, заполняем, применяем. 

3 После выполнения плейбука, у вас 3 настроенных сервера-стенда.
